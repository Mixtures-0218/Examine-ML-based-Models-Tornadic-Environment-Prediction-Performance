# FSS Neighborhood Size Verification
As FSS can be higher when its neighborhood size getting larger, we followed Antonio, B., and L. Aitchison, 2025: How to Derive Skill from the Fractions Skill Score. Monthly Weather Review, 153, 1021–1033, https://doi.org/10.1175/MWR-D-24-0120.1. to verify which size can reflect the forecast skill the most effective

This script only works when the tornado-relevant parameters were correctly saved

The result shows 3x3 size is the best (away from FSS_random) in all lead times and tornado-relevant parameters
