# FengWu Model Inference Process

## All necssary model files should be downloaded from the original GitHub page
https://github.com/OpenEarthLab/FengWu

## Inference
The target time in the `inferece.py` should be correctly seted

The scripts will automatically gather data for lead times 24h, 48h, 72h, 120h, and 168h

Then run the script `output_decode.py` once the is correctly seted. This script will automatically run all 3 py scripts
